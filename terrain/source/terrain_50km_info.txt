6. FILE GENERATI
----------------

  GeoTIFF master georeferenziato 32-bit float con quote reali in metri, proiezione EPSG:32632.
- terrain_50km_worldmachine.r16:
  File RAW 16-bit unsigned (uint16 little-endian, byte order Intel), normalizzato su [0, 65535].
  Dimensione esatta: 50,000,000 byte (47.68 MB).
- terrain_50km_preview.png:
  Anteprima ad alta leggibilità con rilievo ombreggiato (hillshade) e tinteggiometria ipsometrica.
- terrain_50km_info.txt:
  Questo documento di riepilogo e configurazione.

7. IMPOSTAZIONI PER L'IMPORTAZIONE IN WORLD MACHINE
---------------------------------------------------
Nel nodo "File Input" di World Machine configurare come segue:
1. File: selezionare "terrain_50km_worldmachine.r16"
2. Format:
   - Type: RAW 16-bit
   - Signed/Unsigned: Unsigned (0..65535)
   - Byte Order: Little Endian (Intel / x86 PC standard)
3. Dimensions:
   - Width:  5000
   - Height: 5000
4. Extents / Placement (Terrain Sizes):
   - Real-world size: 50 km × 50 km (50000 m × 50000 m)
5. Altitude / Elevation Scaling:
   - Minimum Altitude: 11.36 m
   - Maximum Altitude: 3452.75 m
   (Oppure impostare Elevation Scale = 3441.39 m e Offset = 11.36 m).
   In questo modo World Machine mapperà il valore uint16 0 a 11.36 m
   e 65535 a 3452.75 m, ripristinando al millimetro le quote reali del terreno.
6. Orientamento assi:
   - Il file è memorizzato top-down (riga 0 = Nord / Y_max, riga 4999 = Sud / Y_min).
   - In World Machine, lasciare "Flip Y" deselezionato (o verificare l'anteprima se il nord è in alto).
